## Baseball Player Stats Table 2.0 (Now with users)

You can find the Baseball Player Stats Table 2.0 at [https://a3-rashi-roselin.onrender.com/](https://a3-rashi-roselin.onrender.com/)


This application uses a simple username and password system to allow users to compile a table for their favorite baseball players and their stats. I chose a simple system because it was one I knew how to implement. The CSS framework I used was Pico, and I made some modifications to colors and sizes.
